Como obter uma chave de API

Entre no painel do provedor, configure o acesso à API e crie uma chave. Copie-a e salve no cartão correspondente abaixo.

  • Google Gemini: Google AI Studio → API keys
  • DeepSeek: Platform → API keys
  • Anthropic: Claude Console → API keys
  • OpenAI: Platform → API keys
  • OpenRouter: Settings → API keys

O uso é cobrado na sua conta do provedor. Configure os limites de gasto disponíveis no painel dele. Depois de salvar, escolha o modelo em Preferências de modelos. Acompanhe as chamadas em Seu uso.
