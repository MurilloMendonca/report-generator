API pública ou autenticada? Configure ambas aqui. Depois, selecione o conjunto ao criar seu relatório.

01

Conecte uma origem

Onde seus dados estão?

Salve o endereço e, se necessário, as credenciais de acesso. Elas ficam criptografadas na sua conta.

+ Adicionar conexão
Para uma API pública, escolha “Sem autenticação” abaixo.
Use um usuário com permissão apenas de leitura. Redes privadas precisam de autorização do administrador.
Sem TLS, a senha e os dados trafegam sem criptografia. Use apenas credenciais e dados públicos, como os do RNAcentral.
Ao editar, deixe vazio para manter a credencial. Informe-a novamente se mudar o destino, a autenticação ou a segurança da conexão.
02

Escolha o que importar

Crie conjuntos prontos para seus relatórios.

Um conjunto é um endpoint da API, uma tabela ou uma consulta. Ajuste os filtros em cada relatório sem refazer a conexão.

+ Adicionar conjunto de dados
Relativo ao endereço base. Deixe vazio para usar o próprio endereço da conexão. Use um JSON Pointer, como /data/items. Deixe vazio para detectar os registros.
A importação só aceita o conjunto completo. Se atingir um limite, restrinja os filtros.
Use parâmetros no formato %(nome)s. As consultas são executadas em transações somente de leitura.
Valores de texto, número, booleano ou null. Em APIs, null omite o parâmetro. Credenciais devem ficar na conexão.

Prévia dos dados

Amostra de até 5 registros. A importação no relatório cria um snapshot completo.
