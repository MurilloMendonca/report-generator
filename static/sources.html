Conexões

As credenciais ficam criptografadas na sua conta. Use uma conta de banco com acesso restrito aos dados necessários. Para APIs, o teste consulta a URL base; use a prévia do conjunto para testar um endpoint.

Adicionar conexão
TLS com certificado válido é obrigatório. Redes privadas precisam ser autorizadas pelo administrador da aplicação.
Ao editar, deixe vazio para manter a credencial. Informe-a novamente se mudar o destino ou a autenticação.

Conjuntos de dados

Cada conjunto define um endpoint, tabela, view ou consulta. Os parâmetros podem ser ajustados em cada relatório.

Adicionar conjunto de dados
Use um JSON Pointer, como /data/items. Deixe vazio para detectar os registros.
A importação só aceita o conjunto completo. Se atingir um limite, restrinja os filtros.
Use parâmetros no formato %(nome)s. As consultas são executadas em transações somente de leitura.
Valores de texto, número, booleano ou null. Em APIs, null omite o parâmetro. Credenciais devem ficar na conexão.

Prévia dos dados

Amostra de até 5 registros. A importação no relatório cria um snapshot completo.
